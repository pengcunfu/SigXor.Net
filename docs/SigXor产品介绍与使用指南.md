# SigXor 产品介绍与使用指南

## 一、产品简介

SigXor 是一款轻量、本地化的桌面效率工具，主要提供两类能力：

- **语音输入**：按住快捷键说话，识别结果自动输入到当前光标位置，全程本地离线识别；
- **区域截屏 + OCR**：一键框选屏幕任意区域，截屏后可复制、保存，并能本地识别图中的文字。

所有识别（语音、OCR）都在本机完成，不上传任何数据，无需联网即可使用。

---

## 二、核心功能

| 功能 | 说明 |
| --- | --- |
| 语音输入 | 按住右 Alt 说话，松手后自动把识别文字输入到当前焦点位置 |
| 多语言语音识别 | 基于 SenseVoice 模型，支持中文、英文、日语、韩语、粤语 |
| 区域截屏 | 按 Fn + ` 进入选区模式，拖动框选任意区域，或双击直接截全屏 |
| 截屏工具条 | 截屏后自动弹出：OCR 识别、复制图片、保存、完成 |
| OCR 文字识别 | 基于 PaddleOCR PP-OCRv6 模型，本地识别中英文混排文字，结果弹窗展示 |
| 系统托盘 | 最小化到托盘、托盘菜单可显示主窗口或退出 |
| 开机自启动 | 可选开机静默启动（仅托盘运行） |

## 三、系统要求

| 平台 | 支持情况 |
| --- | --- |
| Windows 10 / 11 | 完整功能（语音、截屏、OCR 均可用） |
| Linux | 界面与模型管理可用，语音输入需安装 xdotool 等依赖 |
| macOS | 界面与模型管理可用，语音输入需授予辅助功能权限 |

其他要求：

- 电脑需安装 .NET 10 运行时（使用发布包时一般已自带）；
- 首次使用语音或 OCR 前需要联网下载模型（一次性）；
- 语音输入需要麦克风设备。

## 四、快速开始

### 1. 启动程序

双击 SigXor.exe 即可运行。首次启动后程序会出现在桌面，同时驻留系统托盘。

> 提示：如果开启了「开机自启动时静默」，程序启动后不会显示主窗口，只驻留托盘，点击托盘图标可打开主窗口。

### 2. 启动语音服务

打开主窗口「服务」页，点击 **开始服务**，等待模型就绪后即可使用语音输入。

### 3. 开始使用

- 说话前先点击要输入文字的位置（记事本、聊天窗口、网页输入框等）；
- 按下右 Alt 开始说话，松手后文字自动输入；
- 需要截屏时按 Fn + ` 框选区域，再使用工具条完成复制、保存或 OCR。

## 五、使用说明

### 5.1 语音输入

右 Alt 键支持两种操作方式：

- **短按右 Alt**：开始录音，再按一次结束（适合长句、连续说话）；
- **按住右 Alt 松手**：按住期间录音，松手即结束并输入（适合短句）。

识别出的文字会通过两种方式之一写入目标位置：

- **剪贴板粘贴**（默认）：自动复制文字并执行粘贴，速度快、兼容性好；
- **键盘模拟**：逐字模拟键盘输入（适合剪贴板被占用等场景）。

两种方式可在「设置」页切换。

### 5.2 区域截屏

按 **Fn + `** 键（部分笔记本键盘上 Fn 对系统不可见，实际按 ` 键即可）进入选区模式：

1. **拖动鼠标**框选要截取的区域，松手后自动完成截屏；
2. 或**双击**屏幕任意位置，直接截取整个屏幕。

截屏完成后：

- 截图会固定在原位置显示，可**拖拽移动**，方便核对；
- 屏幕下方自动出现**工具条**，可随截图一起移动；
- 按 **Esc** 可随时退出截屏（不复制）。

#### 工具条按钮说明

| 按钮 | 功能 |
| --- | --- |
| OCR 识别 | 本地识别截图中的文字，结果弹窗展示（可复制或关闭） |
| 复制图片 | 把截图图片复制到剪贴板，可直接粘贴到聊天/文档 |
| 保存 | 弹出保存对话框，选择位置保存为 PNG 图片 |
| 完成 | 把截图复制到剪贴板并关闭工具条 |

### 5.3 OCR 文字识别

点击工具条上的「OCR 识别」后：

1. 结果窗口会**立即弹出**，显示识别进度（首次使用会先下载模型）；
2. 识别完成后窗口内展示识别出的文字；
3. 点击**复制**把文字复制到剪贴板并关闭窗口；点击右上角 **✕** 或按 Esc 直接关闭（不复制）。

OCR 模型说明：

- 使用开源的 **PaddleOCR PP-OCRv6** 多语言模型（约 30MB），支持中英文混排；
- 模型下载失败时会自动回退到 PP-OCRv5（约 16MB）；
- 模型下载一次后即**完全离线**，之后不再需要网络。

### 5.4 系统托盘

程序关闭时默认最小化到托盘，不会退出。托盘菜单提供：

- **显示主窗口**：重新打开主界面；
- **退出**：完全退出程序。

## 六、设置说明

打开主窗口「设置」页，可调整以下选项：

| 设置项 | 说明 |
| --- | --- |
| 识别引擎 | 选择语音识别模型（默认 SenseVoice，推荐） |
| 识别语言 | 中文 / English / 粤语 / 日语 / 韩语 / 自动 |
| 显示通知 | 操作结果是否弹出托盘提示 |
| 使用剪贴板粘贴 | 语音结果通过剪贴板粘贴输入 |
| 启用 Fn + ` 区域截屏 | 关闭后快捷键不再响应截屏 |
| 开机自启动时静默 | 开机只驻留托盘，不弹出主窗口 |
| 关闭窗口时最小化到托盘 | 点关闭按钮只隐藏到托盘 |
| 开机自启动 | 登录 Windows 后自动启动程序 |

## 七、常见问题

**Q1：首次下载模型很慢或失败怎么办？**

语音模型约 230MB、OCR 模型约 30MB，下载速度取决于网络。失败后可在「服务」页点击「下载」重试，或在 OCR 结果窗口内重试。删除模型目录后重新下载也可解决文件损坏问题。

**Q2：按 Fn + ` 没有反应？**

先确认「设置」页的「启用 Fn + ` 区域截屏」已勾选。部分键盘 Fn 不传给系统，直接按 ` 键即可触发。

**Q3：OCR 识别不出文字？**

建议框选范围大一些、保证文字清晰；识别结果窗口会提示「未识别到文字」。首次使用需要先下载 OCR 模型（约 30MB）。

**Q4：语音识别结果没有输入到目标位置？**

先点击目标输入框获得焦点，再使用语音；如「剪贴板粘贴」无效，可在设置中切换为「键盘模拟」。

**Q5：我的数据会上传到云端吗？**

不会。语音与 OCR 均为本地模型识别，数据不出本机。截图默认不自动保存，只有点击「保存」才会写入你选择的位置。
